## 📖 Présentation

**P_Web-Statique-293** est un site vitrine multipage réalisé en HTML, CSS et JavaScript dans le cadre du module **P293** à l'ETML.

Le site présente l'histoire de Mercedes-Benz, plusieurs modèles emblématiques et différentes innovations technologiques. Il sert surtout à démontrer la conception d'un site statique structuré, responsive, accessible et cohérent visuellement.

> Ce projet est une réalisation scolaire indépendante. Il n'est ni affilié, ni approuvé, ni sponsorisé par Mercedes-Benz.

## ✨ Fonctionnalités

- page d'accueil avec section principale visuelle ;
- navigation entre plusieurs pages thématiques ;
- présentation de modèles Mercedes-Benz ;
- carrousel interactif ;
- menu hamburger pour les petits écrans ;
- page consacrée à l'histoire de la marque ;
- page consacrée aux modèles ;
- page consacrée aux technologies ;
- page de contact ;
- mentions légales ;
- page de présentation de l'auteur ;

## 🚀 Lancer le site

### Méthode rapide

1. Clone le dépôt :

   ```bash
   git clone https://github.com/Pt74bsx/P_Web-Statique-293.git
   ```

2. Ouvre le dossier `mon-site-web`.
3. Ouvre `index.html` dans un navigateur récent.

### Avec un serveur local

L'utilisation d'un serveur local reproduit mieux le fonctionnement d'un hébergement Web.

Avec Python :

```bash
cd P_Web-Statique-293/mon-site-web
python -m http.server 8000
```

Puis ouvre `http://localhost:8000`.

Avec Visual Studio Code, l'extension **Live Server** peut également être utilisée.

## 📱 Responsive design

Le site est conçu pour s'adapter à plusieurs tailles d'écran :

- navigation complète sur ordinateur ;
- menu hamburger sur mobile ;
- images et blocs redimensionnables ;
- zones de contenu réorganisées selon la largeur ;
- boutons et liens disposant de libellés accessibles.

Pour tester le comportement responsive, utilise les outils de développement du navigateur et vérifie plusieurs largeurs d'écran.

## ♿ Accessibilité

Le projet utilise notamment :

- une langue de document déclarée en français ;
- des balises `header`, `nav`, `main`, `section` et `footer` ;
- des attributs `alt` descriptifs sur les images ;
- des libellés pour les contrôles interactifs ;
- des liens explicites ;
- une navigation structurée.

Des audits Lighthouse et des tests au clavier permettraient d'aller plus loin.

## ⚠️ Limites actuelles

- site statique sans serveur applicatif ;
- formulaire de contact non connecté à un service d'envoi ;
- contenu et médias maintenus manuellement ;
- absence de tests automatisés ;
- aucune interface d'administration ;
- certaines ressources appartiennent à des tiers.
